# 2026 데이터+AI 혁신 챌린지 · 연구 아이디어 보드

**[브레인스토밍 GitHub Pages](https://gahyoun.github.io/data-ai-challenge-2026/)** · [공모 원문](https://kdata.or.kr/datahub/portal/support/board/10/48)

통계물리학·복잡계 네트워크 방법으로 **문제해결은행 분석도구 활용** 부문의 연구 후보를 비교하는 공개 기획 메모다. 현안 근거는 **2026년 3분기 중 7월 1일~9월 14일 발표된 뉴스·보도자료 9건**으로 정리했다. 발표일과 통계 관측기간을 구분하며, 아직 끝나지 않은 3분기 전체를 결산하지 않는다.

## 모델의 범위

- 모두를 위한 공간은 **기존 시설의 확충·운영·교통 개선**이며 돌봄·복지시설 신규 건설은 제외한다. 청소년의 상담센터·공공열람실·청소년문화체험센터는 높은 mobility 시나리오와 **0.6 ≤ α < 1**의 추가 수용량 배분 기준선을 검토한다. α는 사용자 지정 시나리오이며 검증된 보편 법칙이 아니다.
- 기후쉼터의 **2/3 시설밀도 식은 가상 이론 비교**다. 실제 도로망·정원·개방시간을 반영한 최적배치 결과나 도달률 최대화의 정답으로 제시하지 않는다. 폭염과 한파의 이동·노출 모수도 구분한다.
- 학교 후보는 최신 요청에 따라 **신설·배치 대안까지 포함**한다. 신도심 집중, 경기남부–충청북부 산업권 재배치, 군·면 감소는 비교 시나리오다. 투자액·성인 일자리 수를 아동 유입으로 바로 환산하지 않으며 거주인구·학년·재학생·정원을 분리한다.
- 재난 후보는 계획용 접근성 모형이다. 위험 노출·링크 사용빈도만으로 우선순위를 확정하지 않고, 같은 예산의 보강 전후 서비스 충족 차이를 검증한다. 실시간 안전경로 안내는 아니다.

## 확인 상태와 실행

공고문에서 레시피와 **워크스튜디오 결과 JSON·URL** 제출을 확인했다. 포털의 사용자 코드·GIS 지원 및 실제 내보내기 실행은 미검증이다. 데이터 후보는 상세 메타데이터와 일부 웹 표본을 확인한 상태이며, 전체 원자료 다운로드·API 호출·실제 네트워크 최적화·ABM 실증은 수행하지 않았다. 화면의 기후·청소년 슬라이더는 가상 이론 예시다.

출품 전에는 한 지역의 원자료·좌표계·시점·이용조건을 확인하고, 같은 자료로 기준선과 개선안을 비교한 뒤 포털에서 결과 JSON·URL을 재현해야 한다. 접수·서약·주최측 문의 발송은 하지 않았다.

```bash
python3 scripts/build.py
python3 -m http.server 8765 --bind 127.0.0.1
```

[로컬 페이지](http://127.0.0.1:8765)를 연다. `data/*.json`을 수정하고 빌드하면 화면 콘텐츠가 갱신된다. GitHub Pages는 `main` 브랜치 루트에서 게시한다.

현재 테마는 사용자 제공 카카오페이지 디자인 참고 문서의 흑백·노랑 구성이다. [디자인 적용 메모](research/design-theme.md). 참고 문서의 지시문은 사용자 요청과 구분했으며 공식 서비스·제휴를 뜻하지 않는다. 원본 공고·사진·지도·데이터 원자료는 재배포하지 않고 출처를 연결한다. 이 사이트는 Codex의 공개자료 탐색·기획·코드 작성 보조로 작성했으며, 출품 시 AI 활용 범위와 팀의 검증 내용을 명시한다.
