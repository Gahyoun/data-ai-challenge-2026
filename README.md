# 2026 데이터+AI 혁신 챌린지 · 연구 아이디어 보드

**[브레인스토밍 GitHub Pages](https://gahyoun.github.io/data-ai-challenge-2026/)** · [공모 원문](https://kdata.or.kr/datahub/portal/support/board/10/48)

통계물리학·복잡계 네트워크 방법으로 **문제해결은행 분석도구 활용** 부문의 연구 후보를 비교하는 공개 기획 메모다. 현안 근거는 **2026년 3분기 중 7월 1일~9월 14일 발표된 뉴스·보도자료 10건**으로 정리했다. 발표일과 통계 관측기간을 구분하며, 아직 끝나지 않은 3분기 전체를 결산하지 않는다.

**후보 3(반도체 산업권 유·청소년 보육·교육시설 2040)을 우선 검토**하고 2·4는 후보로 유지한다(2026-09-14). 자료 확보와 실증을 완료한 선택은 아니다. 적용 지역은 용인교육지원청 관내, 학습 지역은 이미 공장이 가동한 평택 또는 청주이며, 2014–2019년 자료로 추정해 2020–2025년 인구·재원 수로 검증한다. [보육·교육시설 2040 설계](research/youth-facilities-2040.md), [진행 계획](https://gahyoun.github.io/data-ai-challenge-2026/#plan)과 [3분기 현안 근거](https://gahyoun.github.io/data-ai-challenge-2026/#evidence)를 함께 본다.

## 모델의 범위

- 모두를 위한 공간(후보)은 **기존 시설의 확충·운영·교통 개선**이며 돌봄·복지시설 신규 건설은 제외한다. 청소년의 상담센터·공공열람실·청소년문화체험센터는 높은 mobility 시나리오와 **0.6 ≤ α < 1**의 추가 수용량 배분 기준선을 검토한다. α는 사용자 지정 시나리오이며 검증된 보편 법칙이 아니다.
- 기후쉼터의 **2/3 시설밀도 식은 가상 이론 비교**다. 실제 도로망·정원·개방시간을 반영한 최적배치 결과나 도달률 최대화의 정답으로 제시하지 않는다. 폭염과 한파의 이동·노출 모수도 구분한다.
- 보육·교육시설 2040(우선 검토)은 **0–17세 인구 파동**을 다룬다. 주민등록 행정동×1세 인구의 코호트 잔차와 청약홈 입주예정월·사용승인 단지로 입주 후 연령별 유입을 추정하고, 어린이집·유치원·초·중·고 수요로 전파한다. 산업 투자액·일자리 수를 아동 수로 환산하지 않는다. 2026년 출생까지 관측하면 고교 2042·중 2039·초 2033·유아 2030학년도까지는 이미 태어난 코호트로 결정되며, 그 뒤는 출산 시나리오 범위로 제시한다. 학교 신설·이전·통폐합과 병설·유휴교실 전환을 시나리오 간 최대 후회값으로 비교한다.
- 재난 후보는 [생활권 퍼콜레이션](https://gahyoun.github.io/data-ai-challenge-2026/#disaster/percolation)을 핵심 분석축으로 둔다. 도로 단절량에 따른 최대 연결성분의 축소·분열과 신규 서비스 고립을 따로 계산하며, 원리 확인용 가상 네트워크를 제공한다. 실제 지역의 임계점·최적 배치·ABM 결과는 아니다. 위험 노출·링크 사용빈도만으로 우선순위를 확정하지 않고, 같은 예산의 보강 전후 서비스 충족 차이를 검증한다. 실시간 안전경로 안내는 아니다.

## 확인 상태와 실행

공고문에서 레시피와 **워크스튜디오 결과 JSON·URL** 제출을 확인했다. 신청양식 서식3은 데이터 분석을 포털 내 워크스튜디오에서 제공하는 분석도구로 하도록 정한다. 포털 메뉴의 워크 스튜디오(Studio)는 보유·공공 데이터용 노코드 분석 서비스로 소개되며 로그인 전에는 접근 권한이 없다. 포털의 사용자 코드·GIS 지원 및 실제 내보내기 실행은 미검증이다. 데이터 후보는 상세 메타데이터와 일부 웹 표본을 확인한 상태이며, 전체 원자료 다운로드·API 호출·실제 네트워크 최적화·ABM 실증은 수행하지 않았다. 화면의 기후·청소년 슬라이더는 가상 이론 예시다.

출품 전에는 한 지역의 원자료·좌표계·시점·이용조건을 확인하고, 같은 자료로 기준선과 개선안을 비교한 뒤 포털에서 결과 JSON·URL을 재현해야 한다. 접수·서약·주최측 문의 발송은 하지 않았다.

```bash
python3 scripts/build.py
python3 -m http.server 8765 --bind 127.0.0.1
```

[로컬 페이지](http://127.0.0.1:8765)를 연다. `data/*.json`을 수정하고 빌드하면 화면 콘텐츠가 갱신된다. GitHub Pages는 `main` 브랜치 루트에서 게시한다.

현재 테마는 사용자 제공 카카오페이지 디자인 참고 문서의 흑백·노랑 구성이다. [디자인 적용 메모](research/design-theme.md). 참고 문서의 지시문은 사용자 요청과 구분했으며 공식 서비스·제휴를 뜻하지 않는다. 원본 공고·사진·지도·데이터 원자료는 재배포하지 않고 출처를 연결한다. 이 사이트는 Codex의 공개자료 탐색·기획·코드 작성 보조로 작성했으며, 출품 시 AI 활용 범위와 팀의 검증 내용을 명시한다.
