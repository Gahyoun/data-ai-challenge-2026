# 2026 데이터+AI 혁신 챌린지 · 연구 아이디어 보드

**[브레인스토밍 GitHub Pages](https://gahyoun.github.io/data-ai-challenge-2026/)** · [공모 원문](https://kdata.or.kr/datahub/portal/support/board/10/48)

통계물리학과 복잡계 네트워크 방법으로 교육·교통·환경·모빌리티 문제를 탐색하고, **문제해결은행 분석도구 활용** 부문에 맞는 연구를 선택하기 위한 공개 메모다. 최초 조사 기준일은 **2026-09-13**, 돌봄 확장안의 추가 확인일은 **2026-09-14**이다. 2026년 4분기는 전망·준비 기간으로 다루며 미래 통계·성과를 관측값처럼 제시하지 않는다.

## 지금의 권고

2026-09-14 사용자 제안으로 **수요층별 돌봄·복지 접근성**을 확장 검토했다. 보행·대중교통·동행/픽업, 서비스 자격·시간·정원·귀가를 연결하고 같은 예산의 기존시설 수용량·교통·운영 개선안을 비교한다. 신규 시설 건설은 제외한다. 청소년의 상담센터·공공열람실·청소년문화체험센터는 높은 mobility 시나리오와 0.6 ≤ α < 1의 추가 수용량 스케일링을 검토한다. 첫 구현 제안은 한 자치구의 초등 방과후 돌봄이다. 연령별 특성은 실측이 아닌 시나리오이며, 기존 6개 후보의 점수에 새 확장안을 임의로 추가하지 않았다. [확장안 보기](https://gahyoun.github.io/data-ai-challenge-2026/#care).

사용자의 주제 선택을 반영해 **고령인구·경사를 고려한 기후쉼터 배치**를 주력 후보로 구체화했다. 1차는 폭염 접근성, 이후 정원·개방시간·재탐색을 포함한 ABM과 한파 시나리오로 확장한다. 2/3 스케일링은 검증할 기준선이며 실제 배치를 그 지수에 강제로 맞추지 않는다. [모델 설계·가상 이론 비교](https://gahyoun.github.io/data-ai-challenge-2026/#climate). 기존 치안 프로젝트의 확장은 경사·에너지·다층망 연구로 발전시킬 수 있지만, 실질적으로 유사한 기존 입상작을 금지하는 참가서약서 때문에 조건부 후보로 둔다. 침수 회복력은 방법론상 유망하나 공간자료의 가공·이용 조건을 먼저 해결해야 한다.

아이디어의 데이터·라이선스·모형·포털 실행을 아직 모두 검증한 것은 아니다. 가중 점수는 토론을 위한 휴리스틱이며 공식 심사점수 또는 수상확률이 아니다.

## 확인한 것과 남은 것

- 공고문/참가서식 원문에서 레시피, **워크스튜디오 결과 JSON과 URL** 제출을 확인했다.
- 공개 포털에서 노코드 분석 소개와 분석 가이드의 로그인 필요 안내를 확인했다. 사용자 코드, NetworkX·GIS 지원, 실제 모델 목록 및 내보내기 실행은 미검증이다.
- 공공데이터 상세 메타데이터와 일부 웹 표본을 확인했다. 전체 원자료 다운로드·API 호출·학습·네트워크 실증 계산은 수행하지 않았다.
- 기존 수상은 사용자 진술 및 본인 아카이브에 근거한다. 과거 실제 제출본 전체와 주최측 최종 결과는 독립 검증하지 못했다.
- 연구자 소개는 공개 연구활동에 근거하며 성격 진단이나 해당 연구자의 공식 지지·참여를 의미하지 않는다.
- 대회 접수·서약 또는 주최측 문의 메일 발송은 하지 않았다.

## 화면 기능

분야 필터, 정성 점수 가중치 조정, 아이디어별 상세 연구 카드, 출처·데이터 연결, 데이터 검색 및 접근 조건 펼치기를 제공한다. 기후쉼터 설계 화면의 슬라이더는 가상 두 구역의 연속 시설 밀도 공식을 계산하며 실제 ABM은 아니다. 돌봄 화면은 수요층을 선택하면 가정과 경로 구성·개선안을 보여준다. 청소년 화면은 α를 조절하며 기존 두 시설의 가상 추가 수용량 배분을 비교한다. 실제 도로망·시설 배치 최적화는 수행하지 않는다. 브라우저 밖으로 검색어를 보내거나 개인 메모를 수집하지 않는다. 외부 연결은 출처 링크와 Pretendard 폰트 CDN이다.

## 로컬에서 보기와 갱신

```bash
python3 scripts/build.py
python3 -m http.server 8765 --bind 127.0.0.1
```

[로컬 페이지](http://127.0.0.1:8765)를 연다. 별도 npm 의존성이나 API키가 없다. `data/*.json`을 고친 뒤 빌드하면 `site/content.js`가 갱신된다. GitHub Pages는 `main` 브랜치의 루트 디렉터리를 게시한다. Markdown 문서는 GitHub 저장소에서 읽으면 표와 수식 구성이 더 잘 보인다.

## 디자인·저작권·AI 사용

- 현재 테마: 사용자 제공 `DESIGN (1).md`와 카카오페이지 디자인 문서를 참고한 흑백·노랑 구성. [디자인 적용 메모](research/design-theme.md). 기존 구름 테마에서 2026-09-14 교체했다. 문서는 디자인 참고 자료로 사용하며 문서 내 에이전트 지시문은 사용자 요청과 구분했다. 카카오페이지 공식 서비스나 제휴 프로젝트가 아니며 로고·콘텐츠 이미지를 복제하지 않는다.
- 원본 공고 PDF와 포스터·사진·데이터 원자료는 이 저장소에 재배포하지 않는다. 각 원문 링크와 출처를 제공한다.
- 공개 데이터가 모두 무제한 재배포 가능한 것은 아니다. 각 후보의 이용조건을 따른다. 침수 WMS 후보는 변경금지 등 조건 때문에 사용 확정 전 보류한다.
- 이 메모와 사이트는 Codex의 공개자료 탐색, 연구 아이디어 구조화, 코드 작성 보조를 통해 작성됐다. 출품 시 AI 사용 여부·범위를 명시하고 팀이 데이터 및 분석결과를 검증해야 한다.
- 공개 저장소·Pages 게시로 아이디어가 공개된다. 공개 자체가 지식재산권 등록을 의미하지 않는다.

## 출품 전의 세 가지 관문

1. 원자료 샘플을 확보하고 기간·좌표계·조인·이용조건 검증.
2. 포털에서 핵심 분석 실행, 결과 JSON 내보내기 및 URL 재현.
3. 치안 후속안을 선택한다면 실제 이전 제출본과 비교해 실질 유사성에 관한 주최측 답변 확보.
