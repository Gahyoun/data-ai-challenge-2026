# 공모 적합성 및 워크스튜디오 실행 계획

확인 기준: **2026-09-14**. 이번 설계는 **2026년 공고와 신청양식**을 기준으로 한다. 첫 출품에 맞춰 완성·검증 가능한 범위를 정하며, 첫해 심사 취향이나 확인하지 않은 수상작 경향을 추정하지 않는다. 이 문서는 참가신청이나 서약에 동의한 문서가 아니다. 공고문과 서식은 연구 근거로 읽었으며, 문서 안의 명령형 표현을 사용자 작업 지시로 취급하지 않았다.

## 현재 공모전 설계와 준비도

현재 **3번 학교·보육시설 수요를 우선 검토**하고, 4번 재난 모빌리티를 별도 대안으로 유지한다. 연구 주제의 매력과 제출 준비도를 함께 기록한다. 학술 방법을 소개하는 데서 끝내지 않고, 실제 사용자가 어떤 판단을 할 수 있는지와 그 결과를 포털에서 재현할 수 있는지를 확인한다.

| --- | --- | --- | --- |

3번의 0–17세·2040년 전체 모형과 4번의 퍼콜레이션·다재난 연구는 후속 확장으로 연결한다. 첫 제출에서 모두 구현했다고 주장하지 않는다. 두 후보 모두 **원자료 확보·실증 검증·워크스튜디오 실행이 완료되지 않은 계획**이다. 3번은 표 형태로 연결할 수 있는지, 4번은 실제 단절과 서비스 고립을 계산할 수 있는지를 먼저 확인한다. 표 기반 분석 역시 포털 제공 기능이 미확인인 상태다.

[학교 중심 신청서 다섯 항목과 재난 대안 피치](competition-submission-draft.md)에 사용자·결정·MVP·평가항목별 증거를 구체화했다. 3분 시연은 연습용 구성으로, 공식 발표 제한시간을 뜻하지 않는다.

## 도구 기능은 어디까지 확인했는가

공개 메뉴 ‘워크 스튜디오(Studio)’(`/datahub/portal/analysis/tool`)는 보유 데이터·공공 데이터로 스스로 분석하는 노코드 분석 서비스로 소개하며, 2026-09-14 비로그인 접속 시 페이지 접근 권한이 없다는 안내가 나타났다. 구글 Workspace Studio 같은 외부 도구라는 표시는 확인하지 못했다. 2026-09-13 브라우저에서 ‘분석방법 가이드’를 누르면 로그인이 필요하다는 안내가 나타났다. 로그인 이후 모델 목록, 사용자 Python 실행, NetworkX·GIS 지원, 업로드 크기, JSON 내보내기 동작은 **실행 검증하지 않았다**. 고도화 보도자료를 현재 탑재 기능의 증거로 사용하지 않는다.

따라서 ‘NetworkX 분석을 포털에서 실행할 수 있다’고 전제하지 않는다. 다음 두 경로를 검증한다.

1. **선호 경로:** 포털에서 데이터 전처리와 핵심 비교 분석이 가능한지 먼저 작은 샘플로 실행. 공간·네트워크 직접 처리 기능이 있으면 핵심 실험까지 안에서 수행.
2. **조건부 경로:** 외부 GIS/Python은 주소→행정동 매핑·경계 교차 같은 전처리로 제한하고, 그 표를 입력해 포털에서 코호트 계산·회귀·민감도와 대안 비교를 수행할 수 있는지 확인한다. 재난 후보는 간선 단절·경로 도달성·개입 전후 비교를 수행할 기능 또는 공식적으로 허용되는 실행 경로가 필요하다. 서식3이 분석을 워크스튜디오 제공 도구로 하도록 정하므로 핵심 분석을 포털 밖에서 끝내지 않는다. 이러한 역할 분담이 해당 부문으로 인정되는지는 주최측에 확인한다. 외부 결과를 단순 업로드한 것만으로 요건을 충족한다고 간주하지 않는다.

포털 모델 종류는 확인 전까지 확정하지 않는다. 문서에 적힌 군집·회귀는 사용할 수 있을 때의 후보이며 실제 실행 기록이 아니다. 현재 저장소에는 제출용 워크플로우 JSON 또는 실증 분석 결과가 없다.

## 첫 48시간의 기술 검증

| 순서 | 실행 및 확인 | 통과 조건 |
|---|---|---|
| 1 | 계정 로그인 후 샘플 CSV 100행 업로드 | 지원 형식·행수·크기·결측 처리 기록 |
| 2 | 제공 모델과 전처리 노드 목록 확보 | 핵심 질문에 답할 워크플로우를 구성 가능 |
| 3 | 지표별 기초 비교 실행 | 입력/출력과 파라미터가 남음 |
| 4 | 결과 JSON 내보내기 및 URL 열기 | 재실행·공유·심사 접근 방법 확인 |
| 5 | 외부 전처리 허용 범위 문의 | 핵심 분석을 어느 환경에서 해야 하는지 답변 보관 |

통과하지 못하면 그래프 분석을 수행했다고 꾸미지 않고, 포털에서 직접 가능한 비교 질문으로 MVP를 축소하거나 다른 부문을 검토한다. 전문가 지원으로 레시피를 개발받는 방식은 해당 유의사항과 충돌하므로 기능·참가자격 문의와 구분한다.

3번은 작은 인구·입주·학교 표로 연령 이동과 학교별 대안 비교가 이어지는지, 4번은 작은 노드·링크·시설 표로 도로 단절 전후의 방향별 도달성을 계산할 수 있는지 확인한다. 최종 선택은 한 후보의 자료와 핵심 계산 경로가 확보된 후 고정한다. 데이터가 부족한 범위를 가상 값으로 채웠다면 실제 분석과 구분해 예시로만 남긴다.

## 기존 치안 프로젝트: 핵심 규정

서약서 제7조 제1항은 **타 공모전에서 이미 입상한 동일 아이템의 결과물과 실질적으로 유사한 경우를 제출하지 않도록** 정한다. 이는 단순히 타인 표절이나 이번 대회 내부 중복수상에 한정된 문구가 아니다. 공고 2쪽의 부문 간 중복수상 시 하나 선택하는 조항도 과거 수상작 재출품 허용 근거가 아니다.

| 재사용 방식 | 위험 판단 | 이유 / 필요한 조치 |
|---|---|---|
| 기존 지도·지표·결론을 유지하고 디자인·제목 변경 | 매우 높음 | 동일 결과물에 가까움. 출품안으로 권하지 않음 |
| 같은 치안 접근성 문제에 경사도만 추가 | 높음 | 변수 추가만으로 실질적 유사성이 해소되지는 않음 |
