# 연구 설계: 접근성과 회복력을 검증 가능한 질문으로

기준일 2026-09-13. 아래 수식·실험은 제안 설계이며 실증 추정치가 아니다.

## 우선 권고

사용자 선택에 따라 **고령인구·경사 제약을 고려한 기후쉼터 배치**를 먼저 검증한다. [ABM·스케일링 상세 설계](climate-shelter-abm-scaling.md)에 개인 이질성, 2/3 기준선, 정원·대기·재탐색을 구체화했다. 학교 접근성은 대안으로 유지한다. 관심사인 교육·환경·모빌리티와 네트워크 연구가 직접 연결되고 기존 치안 수상작과 문제·수혜자·산출물을 분리하기 쉽다. 실제 우선순위는 데이터 샘플 확보와 포털 실행 검증 이후 확정한다.

치안 확장은 별도 연구 잠재력은 있으나, 기존 공개 프로젝트가 이미 접근성·최적화·에이전트 모형을 포함하므로 ‘AI 에이전트 지도’를 핵심 차별점으로 삼기 어렵다.

## 공통 지표와 대조군

교차로/보행 연결점은 노드, 통행 가능한 도로는 간선이다. 시설은 목적지, 인구격자는 수요다. 도로 길이, 이동수단, 경사, 신호/횡단, 운영시간에 따라 간선 비용을 달리한다. 시설 좌표를 가장 가까운 간선에 붙일 때 연결 거리와 차도/보도 구분을 감사한다.

- **도달가능 인구 비율:** A(τ) = Σᵢ wᵢ I[minⱼ Tᵢⱼ ≤ τ] / Σᵢ wᵢ. τ는 정책적 목표시간 또는 시나리오이며 보편적인 법정 기준으로 제시하지 않는다.
- **최악집단 부담:** 접근시간 상위 10% 또는 취약집단별 P90, 도달불가 비율. 도달불가를 임의로 큰 유한 시간으로 바꿔 평균을 계산하지 않는다.
- **도로 충격 회복력:** 제거 비율 p별 도달가능 인구 R(p). 비교 범위 내 면적과 시설별 접근 손실을 사용. 고립 지점은 별도 표시.
- **효과:** 기준 배치 대비 도달가능 인구 증가, P90 감소, 예산 단위당 접근 손실 감소. 실제 현장효과·범죄감소·사고감소와 같다고 말하지 않는다.

기준모형은 직선거리, 평지·동일속도 도로망, 기존 시설 배치, 예산이 같은 단순 탐욕 배치다. 신규 모형과 동일한 데이터·예산·이동수단을 적용한다. 회귀·군집은 패턴을 요약하는 보조수단이며 인과효과를 입증하지 않는다.

## 통계물리학을 쓰는 이유

도로 일부의 차단이 단순한 거리 증가를 넘어 접근망의 연결 단절을 일으키는지 확인한다. 무작위 제거와 침수·급경사·병목에 따른 표적 제거를 비교하고 유한 네트워크의 연결성 변화, R(p), 시설 접근 손실의 비선형성을 측정한다.

단일 도시에서 급격한 곡선이 나온 것만으로 보편적 임계현상·멱법칙·임계지수를 주장하지 않는다. 임계 거동을 연구하려면 여러 크기/지역과 유한크기 효과, 널모형 비교가 필요하다. 대회 MVP에서는 ‘퍼콜레이션에 기반한 연결성 스트레스 테스트’ 정도의 주장으로 제한한다.

널모형은 공간과 비용 제약을 유지해야 한다. 무작위 시설 배치는 설치가능 후보·시설 수·비용·지역별 수요 구성을 유지한다. 도로 제거는 길이·도로등급·공간 군집을 맞춘 층화 대조군과 비교한다. 순수 차수 보존 재배선만으로 지리 네트워크의 현실적인 대조군이 된다고 가정하지 않는다. 난수 시드와 반복 수를 남기고 신뢰구간/분포를 제시한다.

## 치안 확장을 한다면 새 질문

“보행형 순찰봇과 차량형 순찰 자원을 함께 배치했을 때, 경사·배터리·도로계층 제약 때문에 도달할 수 없는 생활권은 어디이며 동일 예산으로 그 공백을 얼마나 줄일 수 있는가?”

지역 내부망과 지역 간 간선망은 **이동수단별 별도 층**으로 두고 환승/인계 가능 거점만 연결한다. 보행형 로봇이 고속도로를 주행한다고 가정하지 않는다. 고속도로 층의 자원은 별도 차량형 자원 또는 지역 간 이송·인계 시나리오이며, 실제 운행 허가·실증은 이번 계획의 범위 밖이다.

| 설계 | 내용 |
|---|---|
| 비용 | 시간 최소화 목적함수와 별도 에너지 예산 제약. 단위가 다른 시간·에너지를 그대로 더하지 않는다. 이동불가 간선은 사용금지로 처리 |
| 경사 | 이동 방향별 경사; DEM에서 산출한 도로 경사는 측정오차 포함. 육교·터널·교량은 지표고도와 분리 |
| 에너지 | E = 이동 기본소모 + 등판/노면/정지 소모. 로봇 실측 계수가 없으면 구간 민감도 시나리오로만 제시 |
| 제약 | 배터리 잔량, 충전거점, 폭/단차/계단, 교통수단별 접근 제한, 야간 운영 여부 |
| 목적함수 | 같은 예산에서 도달가능 인구 최대화 + 최악집단 접근시간 최소화. 두 목적의 절충을 공개 |
| 제거 실험 | 경사 제외, 배터리 제외, 지역간 층 제외, 인구 형평성 제외를 각각 비교 |
| 검증 | 기존 정적 배치 / 단일 층 / 평지 가정 / 단순 최단경로와 비교; 지역 외 검증 |
| AI 역할 | 관측 수요를 예측하는 모델 또는 제약 내 계획 정책. LLM은 결과 설명·질의 인터페이스에 한정 가능 |

에이전트 수를 늘리거나 ‘멀티에이전트’라는 이름을 붙이는 것은 연구 기여가 아니다. 정책이 어떤 상태를 관측하고 어떤 행동을 하며, 보상·제약이 무엇인지 정의해야 한다. 충분한 학습·검증 데이터가 없으면 강화학습 대신 재현 가능한 최적화/휴리스틱을 사용한다.

## 작은 MVP

경사 차이가 있는 한 시군구와 인접 간선 연결만 선택한다. 전국 모형, 실제 범죄예측, 로봇 하드웨어 개발은 범위에 넣지 않는다. 최초 분석단위는 확보 가능한 도로 간선 또는 인구격자이며, 확보되지 않은 격자별 학생 수나 범죄 신고 위치를 만들어 사용하지 않는다.

1. 인구/시설/도로/고도 네 종류의 작은 샘플을 확보한다.
2. 좌표계·갱신연도·행정구역 코드·연결 오류·결측을 감사한다.
3. 평지 기준과 경사 제약 모형을 비교하고, 최소 3개의 속도/경사/운영시간 시나리오를 사전 정의한다.
4. 공간 블록 또는 지역을 분리해 일반화 가능성을 확인하고, 실제 이동시간 표본이 있으면 오차를 검증한다.
5. 포털에서는 인정 범위 내에서 접근성 격차와 개입 대안을 비교하고 파라미터와 출력 파일을 보관한다.

DEM 또는 보행망을 확보하지 못하면 경사 기반 순찰봇의 핵심 검증은 불가능하다. 이 경우 학교/쉼터/대중교통 접근성의 단순 도로망 MVP로 전환하되, 확보하지 못한 경사를 반영했다고 표기하지 않는다.

## 기대이득과 비용

- 기존 공간 전처리·시각화 경험과 팀원의 고속도로 모빌리티 역량이 출발 비용을 낮출 수 있다. 실제 재사용 가능한 소스·권리 확인은 필요하다.
- 다층 접근성·공간 널모형·불확실성 분석은 대회 이후 연구논문이나 지방정부 의사결정 도구로 이어질 여지가 있다. 논문 게재·수상·정책 도입을 보장하지 않는다.
- 고속도로와 보행봇을 한 장에 결합하는 서사보다 서로 다른 이동수단과 운영 주체 사이의 인계 조건을 정의하는 것이 어렵고 핵심적이다.
- 지형·보도·통행 제약과 실측 에너지 계수 확보, 기존 수상작과의 차별성 소명, 포털 지원 범위가 추가 비용이다.

경제성은 ‘절감액 실측’이 아니라 분석 시나리오로 산출한다. 예: 연간 시간 절감 × 인건비 환산 − 로봇/충전/유지보수 비용. 관측하지 않은 수치로 편익비를 확정하지 않는다.
