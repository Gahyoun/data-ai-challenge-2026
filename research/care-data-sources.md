# 돌봄·사회복지 접근성: 검증한 데이터 후보

확인일: 2026-09-14. 공공데이터포털의 상세 설명·컬럼표와 정부·공공기관의 공개 안내를 확인했다. 원자료 다운로드, API 호출, 주소 지오코딩, 시설 운영기관 확인은 아직 수행하지 않았다. 아래 여섯 후보는 서로 다른 지역을 포함한 **선정용 목록**이며, 하나의 분석에 그대로 합치는 자료 묶음이 아니다.

연령대별 이동 특성은 사용자가 제안한 실험 시나리오다. 이 자료들이 청소년의 장시간 보행이나 모든 고령자의 대중교통 이용 가능성을 입증하지는 않는다. 연령과 별도로 이동 제약, 동행·픽업 가능 여부, 서비스 이용 자격을 기록해야 한다.

## 1. 대전광역시 서구 다함께돌봄센터 운영현황

- [공공데이터포털 상세](https://www.data.go.kr/data/15104110/fileData.do)
- **형태·시점:** CSV, 파일명 기준 2025-07-23, 수정일 2025-07-23, 연간 갱신, 포털 표시 18행. 차기 등록 예정일이 2026-07-24여도 실제 2026 파일 확인을 대신하지 않는다.
- **확인한 컬럼:** 시설명, 행정동·법정동과 각각의 코드, 지번·도로명주소, 연면적, 운영인력, 개소일, 정원, 이용대상, 운영시간, 운영내용 등.
- **활용:** 아동 돌봄시설의 위치·서비스 대상·시간·정원을 함께 구성할 수 있는 유망한 소규모 시작점. 좌표 컬럼은 확인되지 않았으므로 주소 지오코딩과 실제 출입구 연결이 필요하다. 이용대상·운영시간 필드는 있지만 개별 행의 값과 학기·방학 구분은 아직 확인하지 않았다.
- **제약:** 공란은 미집계·부재 또는 비공개일 수 있다. 정원을 빈자리나 추가 수용 가능 인원으로 간주하지 않는다.
- **접근·이용:** 무료, 이용허락범위 제한 없음(포털 표시). 파일은 로그인 없이 다운로드 안내, 변환 API는 가입·활용신청 필요.

## 2. 부산광역시 기장군 지역아동센터

- [공공데이터포털 상세](https://www.data.go.kr/data/15035067/fileData.do)
- **형태·시점:** CSV, 2025-09-17 기준, 수정일 2025-11-21, 연간 갱신, 포털 표시 11행.
- **확인한 컬럼:** 시설명, 우편번호, 소재지, 위도, 경도, 정원, 현원, 종사자, 신고일, 면적, 연락처 등.
- **활용:** 좌표와 정원·현원이 함께 있어 시설 공급 규모를 분리하여 다루기 좋다. 노인복지관 자료와 같은 부산 지역에서 시설 유형별 접근성을 비교하는 후보가 된다.
- **제약:** 컬럼표에는 대상 연령과 운영시간이 없다. 시설별 이용 자격·요일별 운영·학기와 방학 차이·대기 명단을 보완해야 한다. 현원은 특정 시점의 등록 인원일 수 있으므로 `정원−현원`을 임의 방문자의 실시간 빈자리로 해석하지 않는다. 미집계 공란을 0으로 바꾸지 않는다.
- **접근·이용:** 무료, 이용허락범위 제한 없음(포털 표시). 파일 다운로드와 가입·활용신청 방식의 변환 API 안내.

## 3. 부산광역시 노인복지관 현황

- [공공데이터포털 상세](https://www.data.go.kr/data/15042666/fileData.do)
- **형태·시점:** CSV, 파일명 기준 2025-01-01, 등록·수정일 2025-09-02, 갱신주기 월간으로 표시. 포털 설명은 16개 구군의 35개소(본관 26, 분관 9)를 대상으로 한다.
- **확인한 컬럼:** 시설명, 주소, 운영단체·구분, 홈페이지 주소, 위도, 경도, 연락처 등.
- **활용:** 노인 여가·교육·생활 지원 서비스의 거점 위치 후보. 입소형 요양시설과 구분하여 일상 방문 접근성을 연구할 수 있다.
- **제약:** 운영시간, 프로그램별 대상·정원·이용료·현재 모집 상태, 송영차량 노선은 컬럼에 없다. 복지관 한 곳의 좌석 수로 모든 서비스를 합산할 수 없다. 월간 갱신 표시는 현행성을 보장하지 않으므로 이전·폐관도 확인한다.
- **접근·이용:** 무료, 이용허락범위 제한 없음(포털 표시), 파일 다운로드·변환 API 안내. 연락처·시설장 이름은 모델 입력에 필요하지 않다.

## 4. 전국어린이보호구역표준데이터

- [공공데이터포털 상세](https://www.data.go.kr/data/15012891/standard.do)
- **형태·시점:** CSV/XLS/JSON/XML/RDF와 API 안내. 갱신 반기, 메타 수정일 2026-03-31. 확인한 웹 표본의 데이터기준일자는 2026-07-28이며, 전체 자료는 행별 기준일이 다를 수 있다. 기관 자료를 매월 초 병합한다는 안내가 있다.
- **확인한 컬럼:** 시설종류, 대상시설명, 주소, 위도·경도, 관리기관·관할경찰서, CCTV 설치 여부·대수, 보호구역 도로폭, 데이터기준일자.
- **활용:** 어린이 보호구역 관련 시설 위치를 보행망에 연결하고 현장 점검·안전시설 보강 후보를 선별하는 보조 자료.
- **제약:** 제공 범위에서 노인·장애인 보호구역은 제외된다. 좌표는 보호구역의 정확한 경계나 모든 도로 링크를 뜻하지 않는다. CCTV 존재나 보호구역 지정만으로 안전 확률을 산정할 수 없고, 미지정 도로를 위험 도로로 단정할 수도 없다. 횡단보도·보도 연속성·차량 속도·교통 노출량은 별도 확인한다.
- **접근:** 그리드 다운로드 5만 건 제한 안내. 표준자료 및 제공기관별 이용조건을 최종 다운로드 때 확인한다.

## 5. 국가교통DB(KTDB) 대중교통 GTFS 기반정보

- [2026-09-07 공식 배포 공지](https://www.ktdb.go.kr/www/selectBbsNttView.do?bbsNo=2&key=45&nttNo=3825), [공식 자료목록](https://www.ktdb.go.kr/www/selectPbldataChargerWebList.do?key=12&searchClStepCode=106)
- **자료 시점과 배포일 구분:** 2026-09-07부터 제공하지만 **2025년 3월 평일 1일** 기준이다. 전국·도서지역 대상이며 시내·마을버스, 도시철도, 시외버스, 철도, 공항버스, 연안해운, 국내 항공 등을 포함한다고 공지한다.
- **확인한 제공 내용:** 정차지, 노선 기본정보, 운행회차, 회차별 경유 정차지의 도착·출발시각, 도시철도·철도 간 환승정보. 실제 파일의 컬럼명과 선택 지역 누락률은 수령 후 확인해야 한다.
- **활용:** 보행 접근·대기·승차·환승·하차 후 보행을 합친 시간 의존 네트워크. 시설에 갈 수 있어도 운영 종료 뒤 귀가편이 없는 상황을 검사할 수 있다.
- **접근·제약:** 홈페이지 정보공개 → 자료신청 → 교통분석자료 → 교통망 GIS DB → 대중교통. 신청·승인·라이선스·재배포 조건은 아직 확인하지 않았다. 기관은 ID 체계 등이 표준화되지 않은 파일럿 자료라고 명시한다. TAGO 정류소 ID와 직접 동일시하지 않으며, 실시간·주말·2026년 현행 운행표로 표현하지 않는다.

## 6. 경기도 화성시 시내버스노선현황 — 배차 기반 대안

- [공공데이터포털 상세](https://www.data.go.kr/data/15041828/fileData.do)
- **형태·시점:** CSV, 파일명 기준 2026-02-01, 수정일 2026-02-13, 연간, 포털 표시 169행.
- **확인한 컬럼:** 관할관청·업체·노선번호·기종점·인가거리·인가대수, 평일·토요일·일요일·공휴일의 상하행 첫차·막차, 각 요일의 출퇴근 및 일반 배차.
- **활용:** 화성을 연구 지역으로 택하면 기존 TAGO 정류소·경유노선에 서비스 시간과 배차 시나리오를 보완할 수 있다.
- **제약:** 모든 정류소의 회차별 도착시간표는 아니다. 노선번호만으로 TAGO와 자동 결합하지 말고 관청·방향·기종점 등을 대조한다. 배차간격 절반을 대기시간으로 쓰는 경우 무작위 도착 등 가정을 명시하고 민감도 분석한다. 공란은 미집계이며 운행 없음으로 단정하지 않는다.
- **접근·이용:** 무료, 이용허락범위 제한 없음(포털 표시), 로그인 없는 파일 다운로드 안내.

## 기존 데이터와 결합할 때

- 기존 D01 표준노드링크는 차량 도로망이다. 보도, 계단, 횡단보도, 통행금지, 시설 출입구가 포함된 보행 그래프를 대신한다고 가정하지 않는다. 도로와 보행 층은 별도로 검증하여 연결한다.
- D02 DEM은 경사 보조 입력이며 교량·지하도·보도 턱의 실제 통행 가능성을 보장하지 않는다.
- D08·D09 TAGO 정류소·노선 후보는 이번 목록과 중복 생성하지 않는다. GTFS는 시간축 보완 자료이며 결합 ID 체계가 다를 수 있다.
- D16 연령별 격자인구는 잠재 수요의 분모다. 프로그램별 이용 자격·돌봄 필요·이용 의사를 별도로 설정한다. 학교 재학생 수 D07을 집 출발 수요의 위치로 쓰지 않는다.
- D10 시군구 사고 집계는 개별 도로 위험값이 아니다. 이번 스쿨존 자료도 안전성의 완전한 측정값이 아니므로, 검증되지 않은 합성 안전 점수는 시나리오로 표시한다.

**지역 선정 기준:** 시설의 시간·정원·대상 정보를 확보할 수 있는 자치구 하나를 먼저 택한다. 대전 서구는 돌봄 운영 필드가 풍부하고, 부산 기장군은 아동센터 정·현원과 부산 노인복지관 위치를 함께 검토할 수 있다. 어느 곳도 이 목록만으로 완전한 보행·교통·운영 데이터가 갖춰졌다고 판단할 수는 없다. 픽업 의존도와 보호자 시간표, 시설 송영의 실제 운영 여부는 추가 수집이 필요한 핵심 공백이다.
