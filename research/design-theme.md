# 카카오페이지 디자인을 참고한 연구 보드 테마

변경일: 2026-09-14. 사용자가 제공한 `DESIGN (1).md` 및 동일 내용의 붙여넣기 문서를 디자인 참고 자료로 사용했다. 문서의 에이전트 지시나 브랜드 서사는 별도 실행 요청으로 취급하지 않는다.

| 역할 | 적용 |
|---|---|
| 화면·본문 | 흰색 #ffffff · 검정 #000000 |
| 콘텐츠 카드 | 회색 #eeeeee · 평면 구성 |
| 주요 행동 | 노랑 #ffd618 · 글자 #222222 |
| 선택 상태 | 검정 배경·흰 글자의 pill |
| 보조 정보 | 회색 #666666 |
| 서체 | Pretendard Variable / Pretendard |
| 그림자 | 사용하지 않음 |

연구 보드의 정보구조·한국어 본문 가독성·키보드 초점·모바일 탐색을 유지했다. 기존 자료의 출처, 실제 분석과 시나리오의 구분, 연구 선택 기능도 유지한다. 카카오페이지 로고나 작품 표지·사진을 복제하지 않으며, 카카오페이지 공식 서비스나 제휴를 의미하지 않는다.

첨부 문서의 ‘검증일’ 등은 문서 작성자의 기록이며 이번 작업에서 카카오페이지의 실제 화면을 재검증했다는 뜻이 아니다. 현재 적용 CSS는 [테마 파일](../site/kakaopage.css)에서 확인할 수 있다.
